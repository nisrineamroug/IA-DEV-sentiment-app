# TP5 : interface Streamlit

L'interface propose une analyse individuelle et l'analyse d'un CSV contenant une
colonne `review` ou `text`. Elle affiche le label, la confiance et le message
d'abstention ; les erreurs de validation et d'indisponibilité de l'API sont traduites
en messages lisibles.

Le CSV de sortie contient les colonnes d'origine, `label` et `score`, et peut être
téléchargé depuis l'interface.
